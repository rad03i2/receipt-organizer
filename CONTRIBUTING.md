# Contributing

Thanks for improving Receipt Organizer.

1. Fork or branch from `main`.
2. Use Python 3.10+ and install with `python -m pip install -e .`.
3. Keep runtime dependencies at zero unless a dependency solves a substantial, documented problem.
4. Add or update tests for behavior changes.
5. Run `python -m unittest discover -s tests -v` before submitting changes.
6. Keep financial/privacy behavior explicit: never add telemetry, remote uploads, or destructive defaults without clear opt-in.
7. Update both English and Arabic README sections when user-visible behavior changes.

Use focused commits and explain observable behavior in pull requests. Do not commit real receipts, credentials, private financial records, generated databases, or exported personal data.
